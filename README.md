# Beauty Development Studio — painel pessoal

Site estático publicado pelo **GitHub Pages** a partir deste ramo (`gh-pages`).

- Endereço: https://juliaschuler1.github.io/pesquisaedesenvolvimento/
- Os dados (projetos, atividades, fornecedores, clientes, embalagens) ficam guardados **no navegador** de quem usa (IndexedDB). Nada é salvo no GitHub.
- Backup: menu **Dados e backup → Baixar backup**. Para usar em outro aparelho, restaure o backup lá.
- A planilha de fornecedores é importada em **Dados e backup → Importar planilha** (formato em matriz: fornecedor × tipo de produto, com “Apto”).

Arquivos: `index.html`, `styles.css`, `app.js`, imagens ilustrativas de tipos de embalagem em `img/embalagens/`, leitor de Excel em `vendor/` (licença MIT incluída).
